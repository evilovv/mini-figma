## Что НЕ является проблемой (проверено, оставлено как есть)

- Секретов в коде и в истории git нет.
- `Shape` использует `rounded-full` для эллипса — корректно; `box-sizing: border-box` приходит из
  Tailwind preflight, поэтому `width` включает обводку.
- `dist/` в `.gitignore`, в репозитории не отслеживается — правильно.
- Порядок отрисовки: массив фигур, затем черновик — черновик сверху, правильно.
- `screenToCanvas`/`zoomAt`/`clampZoom` согласованы между собой, зум к курсору математически корректен.
- `lang="en"` в `index.html` соответствует английскому интерфейсу — менять не нужно.
- `useShapes.addShape` возвращает `Shape`, хотя вызывающий его игнорирует: безвредно, оставлено.
- GitHub Actions в workflow закреплены по тегу, а не по SHA. Для личного пет-проекта это приемлемо,
  ужесточение не входило в задачу.
